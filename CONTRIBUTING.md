## 🌍 About the Project

**OpenLife** helps people:

* Track daily workflow
* Understand where time goes
* Reflect on habits
* Improve productivity over time

The project is intentionally kept **simple and beginner-friendly** so new contributors can learn **Git, GitHub, and React** in a real open-source environment.

---

## 👥 Who Can Contribute

You can contribute if you are:

* A beginner learning Git/GitHub
* A student or fresher
* A frontend developer (React)
* A designer (UI/UX ideas)
* Someone with ideas or feedback

👉 **No prior open-source experience is required.**

---

## 🛠️ Ways to Contribute

You can contribute by:

* Fixing bugs
* Improving UI
* Adding new components
* Refactoring existing code
* Improving documentation
* Suggesting features via Issues

Look for issues labeled:

* `good first issue`
* `beginner-friendly`

## ⚙️ Project Setup (Local)

### 1️⃣ Fork the Repository

Click the **Fork** button on GitHub to create your own copy.

---

### 2️⃣ Clone Your Fork

```bash
git clone https://github.com/<your-username>/OpenLife.git
cd OpenLife
```

---

### 3️⃣ Install Dependencies (Frontend)

```bash
cd frontend
npm install
npm run dev
```

---

## 📂 Folder Structure (Important)

```
frontend/
├── src/
│   ├── components/   # Reusable UI components
│   ├── pages/        # Page-level components
│   ├── layouts/      # Layout wrappers
│   ├── hooks/        # Custom hooks
│   ├── services/     # API / helper logic
│   ├── styles/       # Global & component styles
│   ├── App.jsx
│   └── main.jsx
```

👉 Please place your code in the **correct folder**.

## 🔄 Contribution Workflow (MANDATORY)

Follow this flow strictly:

### 1️⃣ Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

---

### 2️⃣ Make Your Changes

* Keep changes **small and focused**
* Write clean, readable code
* Add comments if needed

---

### 3️⃣ Commit Your Changes

```bash
git add .
git commit -m "Add: short description of change"
```

---

### 4️⃣ Push to Your Fork

```bash
git push origin feature/your-feature-name
```

---

### 5️⃣ Create a Pull Request (PR)

* Go to GitHub
* Open a PR from your branch → `main`
* Clearly explain **what you changed and why**

---

## 🧑‍💻 Coding Guidelines

Please follow these rules:

* Use **functional React components**
* Keep components **small and reusable**
* Use **clear variable and function names**
* Do not add unnecessary libraries
* Keep UI **simple and accessible**

Add comments like:

```js
// BEGINNER: You can improve this component here
```

---

## 📝 Commit Message Guidelines

Use clear and meaningful messages:

✅ Good examples:

* `Add task card component`
* `Fix layout issue on home page`
* `Update contributing guide`

❌ Avoid:

* `update`
* `fix`
* `changes`

---

## 🔍 Pull Request Guidelines

Before submitting a PR:

* Ensure the app runs without errors
* Keep PRs **small**
* One feature or fix per PR
* Be respectful in discussions

Your PR may be:

* Approved
* Requested for changes
* Merged 🎉
