# Repository SEO Checklist

Use this checklist in GitHub repository settings to improve discoverability and contributor conversion.

## Repository Description

Suggested description:

> Open-source productivity, time-tracking, habit reflection, and workflow analysis app built with React, Vite, Node.js, Express, and MongoDB.

## Website

```text
https://openlife-nine.vercel.app
```

## Pinned Issues

Pin or keep visible:

- Project roadmap and contribution entry point.
- Good first issues list.
- Feature ideas and discussion thread.

## Labels

Keep labels consistent. Recommended groups:

- Type: `bug`, `enhancement`, `📚 documentation`, `💡 feature-request`
- Area: `🎨 frontend`, `⚙️ backend`, `🔌 api`, `🗄️ database`, `UI`
- Contributor: `good first issue`, `Beginner Friendly`, `help wanted`
- Triage: `⏳ needs-discussion`, `🧭 discussion`, `🚨 high priority`, `🤝 community`

## Social Preview

Use a simple image with:

- OpenLife name
- Short tagline: `Reflect on your time. Improve your workflow.`
- Product keywords: `Productivity`, `Time Tracking`, `Habit Reflection`

## README Search Signals

The README should include these phrases naturally:

- open-source productivity app
- time tracking
- habit tracker
- daily reflection
- workflow analysis
- beginner-friendly open source
- React Vite Node Express MongoDB
